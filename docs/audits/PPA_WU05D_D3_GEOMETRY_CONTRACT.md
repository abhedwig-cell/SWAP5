# PPA-WU05-D3 Walsum geometry contract

Proposed separate capability on D2 canonical merge 4fd57c8c8ed321baf6a74214a9720adc899e324d.
D2 is admitted and closed by PR #1012; its qualification record remains authoritative.

Walsum uses the existing root uptake result and compositor, with dynamic ALPHACRIT.
The typed disposable request contains DCRITRTZ, RDM and current rooting depth, all
positive-down centimetres. The existing physical owner's node thicknesses determine
RD_NODDRZ as the bottom of the deepest rooted node, including the whole partially
rooted bottom node. RD_NODDRZ is not replaced by current rooting depth.

The formula is min((DCRITRTZ + RDM - RD_NODDRZ)/RDM, 1). Positive finite RDM,
nonnegative finite DCRITRTZ and 0 <= current depth <= RDM are required. The current
depth must lie within the soil column. Exact node boundaries belong to the node
ending there. Nonpositive effective ALPHACRIT fails closed; no invented lower clamp.
Zero rooting depth permits only zero sink. Positive sink below the deepest rooted
node fails closed. A node bottom may exceed RDM when maximum rooting depth lies
inside that node, provided the resulting ALPHACRIT is positive.

Only the existing Feddes base-sink ownership is qualified. The caller must supply
geometry from the same crop request as its base sink. Geometry is copied from every
forcing, cleared when absent, and re-evaluated for each fresh trial; no accepted
continuation state, water ledger, receipt or restart field is introduced. Jarvis
ignores the optional Walsum request. Existing OFF and Jarvis algebra remain fixed.

Required gates: independent geometry/formula oracle, units/scaling, partial nodes,
changing depth, invalid/NaN inputs, no roots, dynamic alpha, retry/fresh replay,
restart and actual application publication at O0/O2; D2 and oxygen preservation.
Salinity, frost, MICRO and unqualified coupling combinations stay excluded.


## Qualification implementation notes

The application oracle uses the existing 3 cm test column; its first geometry fixture
incorrectly requested 25 cm and was correctly rejected. The corrected fixture uses
RDM=5 cm, DCRITRTZ=0.5 cm, current depth=1.5 cm and node bottom=2 cm (alpha=0.7).
A separate independent geometry oracle covers field-scale 5 to 95 cm depths,
heterogeneous 10/20/30/40 cm nodes, partial deepest nodes and unit scaling.

The scientific admission is bounded to the existing supplied Feddes sink contract,
not a new crop-growth/root-density model or long-duration field validation. Runtime
forcing must be regenerated by its existing crop owner when root geometry changes.
No Walsum-specific persistent state is required for that contract.
