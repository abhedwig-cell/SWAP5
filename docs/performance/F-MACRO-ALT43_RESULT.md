## Independent duration test around 6-10 cm/day

To avoid pseudo-replication, one best matched short/long pair was selected per profile.

Result:

    independent profiles = 174
    short PF fraction     = 0.1149
    long PF fraction      = 0.1034

Discordant pairs:

    long-only PF  = 14
    short-only PF = 16

Exact paired binomial/McNemar p approximately:

    p = 0.856

Interpretation:

The natural NEON events do NOT support a simple monotonic `longer event -> more PF occurrence` signature when events are matched by peak intensity and antecedent-state summaries.

This is important negative evidence against treating ALT40's constant-source mechanistic duration signature as directly observable in aggregated natural-storm descriptors.

It is NOT yet a falsification of RFM-RC1 because:

- `stormPeakIntensity` is a peak 10-minute intensity, not the full effective source time series;
- rainfall temporal structure within the event is not held constant;
- ponding/runoff status is not provided in the compact PF table;
- the binary PF labels are not direct preferential-water fractions.

## Next

The highest-value next step is to identify an authoritative way to bind each NEON profile's antecedent moisture to a constitutive hydraulic state without fitting RFM itself.

Preferred routes, in order:

1. existing measured/NEON profile water-retention parameters;
2. parameters already generated by the dataset authors but not included in the compact PF tables;
3. a separately preregistered pedotransfer sensitivity analysis with uncertainty propagation.

Only after that binding is frozen should sigma_B be estimated on calibration events and tested on held-out events.
