## Scope

D2A executes the first process-coupled empirical tracer subset:

    publication source forcing
      -> RFM unponded surface activation
      -> matrix source -> SWAP5 Richards -> TRACER01 matrix tracer
      -> preferential source -> IC endpoint tracer
      -> sampled 10-cm bromide profile

The matrix source is not obtained by post-hoc scaling. At every accepted step
the current accepted SWAP5 state is used to derive K_surface and S_surface,
RFM activation partitions the source, and only q_matrix is supplied to the
Richards solve.

For this identifiability stage:

    p = 0.249
    f_MB = 0

p is frozen from the previously qualified Profile-1 evidence. No initial theta
or other physical parameter is fitted.
