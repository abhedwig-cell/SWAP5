# F-PE-DYNTOP-PREDICT01 preregistration — origin-frozen surface-transition classifier

Date: 2026-09-28

Status: `PREREGISTERED_BEFORE_RESULTS`

Canonical authority: `integration/f-ci-canonical@94e265d18200b40d942184809e1e45694aea850f`.

Parent authority:

- BOFEK practical and accepted-state controller lines show large-step performance potential but poor wet-transition discrimination.
- EMBEDSTEP02 restores robustness by splitting every large requested interval, but leaves only ~5.7% median deterministic work gain.

## Purpose

Determine whether the existing analytical dynamic-top boundary model can cheaply classify which large requested intervals are safe to execute as one full step and which require temporal splitting.

This is classifier research only. The predictor receives no timestep authority in this workunit.

## Origin-frozen predictor

For every large requested interval `dt > 0.02 d`, before any Richards solve:

1. evaluate the current fixed top-node conductivity at the accepted origin;
2. call the existing corrected dynamic-top provider with:
   - accepted top pressure head;
   - accepted top water content;
   - accepted ponding depth as both previous/origin surface state;
   - proposed large dt;
   - unchanged forcing;
   - fixed-K SWKIMPL=0 semantics.

Record:

- predicted boundary regime;
- predicted ponding depth;
- predicted runoff depth;
- predicted runoff-potential flag;
- predicted surface head;
- predicted net potential surface flux.

No new physical formula is introduced.

## Research label

From the same accepted origin and proposed large interval calculate:

- one full-step trajectory;
- two sequential half-step trajectories.

The local large step is labelled SAFE only if both routes solve and:

- max head endpoint difference <= 0.50 cm;
- ponding endpoint difference <= 0.01 cm;
- runoff-depth difference <= 0.01 cm;
- storage endpoint difference <= 0.01 cm;
- all committed/subtrial ledger residuals <= 5e-8 cm.

Otherwise label UNSAFE.

The two-half endpoint is always committed during classifier data collection, so classifier labels cannot change the future origin path.

## Frozen candidate rules

P0:
- predict SAFE only when `runoff_potential = false`.

P1:
- predict SAFE only when predicted runoff depth = 0 and predicted ponding depth <= 0.005 cm.

P2:
- predict SAFE only when predicted runoff depth = 0 and predicted ponding depth <= 0.020 cm.

P3:
- predict SAFE only when predicted runoff depth = 0 and predicted ponding depth <= 0.050 cm.

No post-hoc threshold additions.

## Calibration bank

Use the already exposed 16 BOFEK01 screening cases.

Large-step origins are generated by the Reference-owned hybrid proposal from EMBEDSTEP02:

- historical Reference TimeControl owns dt <= 0.02 d;
- normalized accepted-state proposal with R=0.40 may request dt up to 0.08 d;
- large intervals are conservatively continued on the two-half route.

## Advancement rule

A classifier rule advances only if:

- at least 10 labelled large-step intervals exist;
- false-safe count = 0;
- it identifies at least 50% of all locally SAFE intervals as SAFE;
- it does not depend on material/regime identifiers.

Select the advancing rule with highest SAFE coverage; tie-break the stricter rule.

If no rule advances, close this origin-frozen predictor family.

If a rule advances, freeze it before constructing a new validation bank.
