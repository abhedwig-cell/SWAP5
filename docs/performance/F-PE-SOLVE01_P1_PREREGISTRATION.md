A local response may be very accurate per discarded request yet still cause extra MODFLOW corrector iterations. If those additional iterations erase the saved SWAP solves, the local P0B speedup is not an application-level gain.

## Final-validation safeguard

Approximate convergence is never sufficient for commit.

Whenever the external corrector satisfies its convergence condition using an approximate SWAP response:

1. execute a real SWAP trial at that candidate head;
2. recompute the physical q mismatch against the live groundwater response;
3. if the exact residual satisfies the frozen coupling tolerance, retain that exact candidate for publication;
4. otherwise discard it, refresh the response anchor from that exact trial and continue the coupled corrector.

Thus an approximate response can steer the iteration but cannot authorize final state.

## Performance interpretation

P1 does not require the full P0B 30% speedup on the existing short F-GC44 loop.

That loop may converge in too few correctors to expose the full solve-elimination opportunity.

Instead P1 first asks whether bounded approximation causes an iteration penalty.

Advance if:

1. E4 or EH does not increase the external corrector count by more than one iteration on the frozen live coupling case;
2. exact final validation succeeds without repeated recovery loops;
3. exact SWAP corrector count is not greater than E0;
4. final endpoint and publication semantics pass.

A positive wall-clock gain is required for a performance claim, but lack of a large gain on a two-iteration live fixture is not by itself a rejection of P0B.

## Stop conditions

Stop the candidate arm if:

- approximate convergence repeatedly fails exact final validation;
- external corrector iteration count grows materially;
- exact refresh amplification removes solve-count benefit;
- endpoint changes beyond existing F-GC44 authority;
- state or ledger ownership differs from E0.

## Decision after P1

If E4 and/or EH pass live coupled-corrector robustness:

advance the surviving arm to a production-shaped difficult-coupling scale test where enough corrector work exists for end-to-end performance authority.

If neither passes:

close bounded solve elimination for the current linear response representation before introducing a more elaborate surrogate.
