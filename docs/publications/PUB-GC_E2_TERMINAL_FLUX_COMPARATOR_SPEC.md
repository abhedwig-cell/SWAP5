# PUB-GC E2 terminal-flux comparator specification

Status: **frozen comparator design before implementation**

Publication owner: `PUB-GC`

Experiment family: `PUB-GC-E2`

Hypothesis: `H2`

Purpose: define a scientifically fair research comparator that isolates **whole-window integrated exchange** from a **terminal-flux surrogate** without changing SWAP state evolution, forcing, candidate head, timestep integration, origin policy, groundwater origin or publication semantics.

This specification creates no H2 result. It must be implemented and independently qualified before any E2 screening or primary comparison.

## 1. Comparator question

For one SWAP trial over coupling window

```text
I = [t0,t1],  Delta t = t1 - t0
```

the qualified SWAP result exposes both:

```text
Q_whole = bottom_outward_exchange_native
```

with units cm and sign positive outward from SWAP, and

```text
q_terminal = terminal_bottom_outward_flux_native
```

with units cm d^-1 and the same outward-positive sign convention.

The terminal-flux comparator is defined as the endpoint rectangular surrogate

```text
Q_terminal = q_terminal * Delta t_days
```

and **only this exchange quantity changes between the two comparator arms**.

Method identifiers:

- `GC-M2-WHOLE`: transfer `Q_whole`;
- `GC-M1-TERMINAL-END`: transfer `Q_terminal`.

No midpoint, start-point, averaged-terminal or fitted correction is part of this comparator. Any later sampling variant requires a separately frozen design.

## 2. Matched semantics

For each paired evaluation, both arms must use exactly the same:

- accepted SWAP origin and checkpoint;
- accepted groundwater origin and checkpoint;
- prescribed bottom-head candidate;
- coupling-window start/end time;
- atmospheric/top forcing;
- soil/material parameters;
- reference B1.10 solver route;
- internal SWAP timestep/retry semantics;
- candidate physical endpoint state;
- terminal flux returned by that same SWAP trial;
- no-production-commit research disposition.

The SWAP trial is executed **once**. The whole-window and terminal-flux arms are alternative interface-accounting interpretations of that exact immutable trial result. The comparator may not rerun SWAP with changed forcing or changed numerical settings.

This is the main fairness condition.

## 3. Groundwater mapping

Use the already qualified transparent `GW-A` component for comparator qualification and controlled E2 work.

For one square metre and the existing GW-A sign convention:

```text
Q_whole_m    = Q_whole_cm    * 0.01
Q_terminal_m = Q_terminal_cm * 0.01
```

Both groundwater candidates start from the **same accepted GW-A checkpoint**.

The whole-window arm receives the paired groundwater exchange corresponding to `Q_whole_m`.

The terminal arm receives the paired groundwater exchange corresponding to `Q_terminal_m`.

Neither arm may commit during comparator qualification or E2 candidate evaluation.

## 4. Conservation diagnostic

The actual SWAP state change is generated by the native SWAP trial and therefore corresponds to `Q_whole`, not to the terminal surrogate.

For the whole-window arm:

```text
epsilon_interface_whole
  = Q_whole + Q_groundwater,outward
  = 0
```

up to arithmetic tolerance when groundwater receives exact action/reaction.

For the terminal arm:

```text
Q_groundwater,outward = -Q_terminal

epsilon_interface_terminal
  = Q_whole - Q_terminal
```

This signed mismatch is a primary E2 diagnostic, not an implementation bug to be corrected away. Correcting it by forcing groundwater to receive `Q_whole` would eliminate the comparator being tested.

Use the magnitude

```text
abs(Q_whole - Q_terminal)
```

for error plots, while retaining the signed quantity in raw telemetry.

## 5. What comparator qualification must prove

Before H2 screening or primary experiments, a research-only qualification harness must prove:

1. both arms consume the exact same completed SWAP trial result;
2. `Q_terminal` is exactly `q_terminal * Delta t_days`;
3. no hidden second SWAP trial is performed to construct the terminal arm;
4. both GW-A candidates start from the same accepted checkpoint;
5. neither groundwater arm commits;
6. whole-window action/reaction closes exactly under the qualified GW-A arithmetic;
7. terminal-arm interface mismatch equals `Q_whole - Q_terminal` exactly within declared arithmetic tolerance;
8. when a synthetic constant-flux trial has `Q_whole = q_terminal Delta t`, both arms are exactly equivalent;
9. changing only the terminal flux while holding `Q_whole` fixed affects only the terminal arm;
10. changing only `Q_whole` while holding the terminal flux fixed affects only the whole-window arm;
11. nonfinite/missing terminal flux fails closed;
12. production `src/**`, the qualified E1 origin harness and qualified GW-A remain unchanged.

Qualification fixtures are infrastructure evidence only and may not be used as H2 primary effect estimates.

## 6. E2 scientific metrics

Once the comparator is qualified, every E2 candidate must retain:

- `Q_whole_cm`;
- `q_terminal_cm_per_day`;
- `Delta t_days`;
- `Q_terminal_cm`;
- signed and absolute `Q_whole - Q_terminal`;
- relative surrogate error when the denominator is scientifically safe;
- GW-A candidate head from `Q_whole`;
- GW-A candidate head from `Q_terminal`;
- paired groundwater-head difference;
- SWAP mass residual;
- transaction retries;
- temporal indicator;
- candidate origin lineage/revision/time;
- exact source/runner/configuration authority.

Later GC-REF experiments add:

- cumulative interface-transfer error versus `GC-REF`;
- groundwater-head error versus `GC-REF`;
- combined coupled mass residual;
- error as a function of coupling-window duration.

## 7. Stress families

Do not select exact primary numeric points from E1 outcomes.

E2 screening should independently cover the pre-existing experiment-matrix classes:

- sharp wetting/recharge transition;
- capillary-rise transition;
- forcing reversal;
- drying/ET transition;
- a ladder of coupling-window durations from near-reference to deliberately long relative to vadose response.

The primary E2 matrix, exact durations and hydrologic cases must be frozen only after comparator qualification and after the `GC-REF` construction rule exists.

## 8. H2 interpretation boundary

The comparator itself cannot establish H2.

Possible future outcomes include:

- `Q_terminal` is nearly indistinguishable from `Q_whole` for practically relevant windows;
- terminal-flux substitution is acceptable only for sufficiently short/quasi-steady windows;
- terminal substitution produces material exchange/head errors in transient windows;
- errors change sign across wetting/drying transitions;
- outer coupling error is dominated by another source, making exchange representation secondary.

All are valid outcomes.

No claim that whole-window exchange is generally superior is allowed until a frozen E2/GC-REF primary matrix demonstrates it.

## 9. Explicit nonclaims

This specification does not establish:

- H2 support;
- practical hydrologic materiality;
- a coupling-window accuracy threshold;
- MODFLOW 6 transferability;
- that terminal-flux coupling is always wrong;
- that endpoint rectangular exchange is the only terminal-flux method used in hydrologic software;
- novelty or priority over prior coupling literature.

## 10. Next permitted action

1. implement the comparator in research-only paths;
2. qualify it against synthetic arithmetic fixtures plus at least one real immutable SWAP trial;
3. persist an immutable qualification receipt;
4. keep `PUB-GC-E2` non-primary until the comparator and `GC-REF` construction are both frozen;
5. only then design screening and a held-out E2 primary matrix.
