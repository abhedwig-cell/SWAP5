## Closure rule

A future source is a **claim-threatening close comparator** if it satisfies most of:

1. mature scientific/process simulator modernization;
2. frozen legacy scientific denominator;
3. strong baseline beyond output-only regression;
4. explicit candidate/speculative vs accepted/committed authority;
5. designed contamination faults;
6. more than one authority sink (state/accounting/restart/workspace/output);
7. measured incremental value as structural prevention or earlier/localized detection;
8. longitudinal use during architectural migration.

No retained source in the 2026-09-18 closure register satisfies this profile from the material reviewed.

That statement is a search result, not a priority claim.
