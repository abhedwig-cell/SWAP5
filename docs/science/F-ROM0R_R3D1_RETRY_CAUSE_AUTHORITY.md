# ROM-0R R3D1 retry-cause authority

R3D1 is diagnostic only.

The accepted predecessor state for each B01 failure is rebuilt through the already qualified Reference-floor sample/commit path. The subsequent failing interval is then evaluated once through the same Reference solver request contract, but the direct diagnostic candidate has no commit authority.

The final Reference workspace is inspected using the already established PUB-P2E11D classification semantics: local compartment-balance flags, pressure-head convergence flags, and the total residual distinguish local-balance, head, mixed, total-only and other retry classes.

This workunit may identify a cause. It may not choose a remedy.

In particular, a local/total balance classification does not automatically authorize the P2E21 representation-bounded policy, because P2E21 was qualified on a different short prescribed-flux population. Likewise, a head or mixed classification does not authorize increasing Newton iterations or reducing dt after observing R3.

Any remedy, if one is scientifically justified, requires a separately preregistered authority workunit.
