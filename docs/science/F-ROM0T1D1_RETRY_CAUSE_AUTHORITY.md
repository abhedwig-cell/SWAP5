From each accepted predecessor it executes the same failing 0.0008-day request once through the direct Reference solver solely to inspect the final private workspace. That direct candidate has no commit authority.

`0.5 * sum((spacing(theta_s) + spacing(theta_base_i)) * dz_i)`.

The observed failed residual is not an input to that bound and no empirical factor is allowed.

A positive diagnostic would establish only that the three T1 refined failures are the same kind of total-column floating-point stopping artifact already characterized elsewhere. It would not itself authorize any alternative Reference policy. Any successor policy must be separately preregistered and must preserve every strict-control accepted overlap state exactly.
