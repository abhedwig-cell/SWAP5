# ROM-1A reachable-state library authority

## Purpose

ROM-1A constructs the accepted full-order state library used by later predictive-state
ambiguity tests. It does not propose or fit a reduced state.

The governing principle is state first, closure second. ROM-1A therefore maximizes
history diversity inside the already qualified pure-hydraulics capability while
preserving strict data-split firewalls.

## Reference authority

Every retained state must originate from the F-KT Reference-floor
sample/candidate/commit ownership path.

The observation step is 0.0008 day. Prescribed-head intervals use the ROM-0R-R3D4
strict-first fail-closed research Reference policy. The original control is always
attempted first. A same-interval fallback is permitted only after immutable
RETRY_TOTAL_ONLY classification within the pre-solve representation bound.

This is research Reference authority only. It is not a production Reference fallback.

## Material split

B01 is the only material visible during ROM-1A/ROM-1B state discovery and
within-material holdout testing.

B14 is declared now as the ROM-1X material-transfer challenge and must not be used to
select, enrich or reject a candidate reduced coordinate before the transfer gate.

This split prevents a state coordinate from being tuned directly to both challenge
materials before transfer is tested.

## History alphabet

No new outcome-selected amplitudes are introduced.

The alphabet is built only from already preregistered ROM-0 perturbations:

- steady qeq;
- top plus/minus 1% K0 about qeq;
- prescribed bottom head 0.75 h0 and 1.25 h0;
- two combined held-out boundary states using those same frozen amplitudes.

The discovery histories span constant forcing, top reversal, lower-boundary reversal
and mixed-order histories. Held-out histories use different segment lengths/order and
one combined top/lower-boundary challenge.

## Split

Discovery:
D01-D08, 64 accepted steps each, 512 accepted states.

Within-material held out:
H01-H04, 64 accepted steps each, 256 accepted states.

The full B01 library target is 768 accepted states.

Discovery outcomes may later be used to propose candidate coordinates. Held-out
history outcomes may only evaluate a frozen candidate and may not drive enrichment.

## Future probes

ROM-1B future probes are frozen before any collision search:

- horizons 4, 16 and 64 samples;
- discovery probes: HOLD, TOP_PLUS, BOTTOM_HEAD_RISE, BOTTOM_HEAD_FALL;
- held-out probes: TOP_MINUS, lower-head rise-to-fall reversal, and the combined
  rise-plus to fall-minus reversal.

Candidate starting states always receive identical future probes.

## Outputs

The primary capability outputs remain total storage, fixed 0-40 cm and 40-160 cm
storage, top and bottom exchange, and water-balance diagnostics.

Full h/theta profiles are retained as full-order diagnostics and as the source from
which future candidate projections may be computed. They are not themselves a ROM
success criterion.

## Firewalls

ROM-1A must not:

- choose a reduced coordinate;
- fit POD/modal coordinates;
- add a memory variable;
- fit closure dynamics;
- inspect B14 outcomes for state design;
- use held-out outcomes for coordinate enrichment;
- derive a ROM accuracy threshold from the generated library;
- claim production readiness.

A positive ROM-1A decision only qualifies the measuring population for ROM-1B.
