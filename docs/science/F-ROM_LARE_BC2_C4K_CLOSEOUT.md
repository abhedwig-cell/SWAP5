# F-ROM-LARE BC2-C4K closeout

Formal decision: CURRENT_STATE_NOT_SHOWN_INSUFFICIENT.

C4K selected cross-direction pairs using only the existing reduced state H, theta_b and theta_t. Full-order local pressure-head geometry was exposed only after that response-blind pairing.

The RISE and FALL trajectories are not near-overlapping manifolds in this state space. Median nearest cross-direction state distance is about 0.128 in the fixed normalized coordinates for both widths, whereas the within-direction control pool reaches only about 0.102 at its upper end. This limits strict distance matching and is itself evidence that motion direction is substantially encoded in the current state.

Cross-direction terminal and adjacent secant slopes differ strongly, but the preregistered insufficiency rule also required curvature ambiguity. That condition is not met. For d=2.5 cm, only about 8.0% of cross-direction pairs have larger curvature difference than the matched within-direction control; for d=5 cm this is about 6.1%. Median cross-direction curvature difference is lower than the matched-control median for both widths.

Therefore C4K does not justify adding a direction/history memory state. It does not prove universal state sufficiency; it only means that current evidence points first toward a better memoryless state-to-gradient representation.

The next candidate should preserve the already-supported qH terminal slope and hydrostatic identity while using the existing Wb/Wt/H information to introduce internal curvature for qi. No free propagation, groundwater feedback, application acceptance or production ROM is authorized.
