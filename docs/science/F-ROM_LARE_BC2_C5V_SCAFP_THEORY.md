# F-ROM-LARE BC2-C5V — SCAFP theory reconciliation

C5V is read-only. It uses no new hydrological response.

## Result

A storage-consistent algebraic subgrid face-profile closure is **possible**, but it is **not uniquely determined** by layer-integrated water storage alone.

For a retained layer state

`S_i = integral theta(psi(z)) dz`,

exact layer conservation constrains only

`dS_i/dt = q_top - q_bottom`.

That fixes the integral storage tendency, not its spatial distribution inside the layer. Darcy-Buckingham supplies a relation between local flux and pressure gradient, but without an additional subgrid profile/tendency principle infinitely many transient fields remain compatible with the same `S_i`.

Therefore the unresolved representation problem is no longer simply state count. It is the missing algebraic rule for within-layer transient structure.

## Why a simple linear pressure profile is not enough

With shared face heads, N layers contain N+1 face-head unknowns. N exact storage constraints plus N-1 internal flux-continuity constraints and two external boundary conditions generally overdetermine a piecewise-linear pressure-head profile. One extra algebraic shape degree of freedom per layer is required.

But theory does not uniquely say how that degree of freedom must be represented. A quadratic pressure profile, a profile in a transformed hydraulic potential, and a profile generated by an affine within-layer flux can all be zero-fit and conservative while remaining structurally different.

## Most conservative candidate if a choice is made

The cleanest conservation-based option is **P0 uniform storage tendency**:

- approximate `dtheta/dt` as constant inside each retained layer;
- continuity then makes `q(z)` linear between the two face fluxes;
- solve `dpsi/dz = q(z)/K(psi) - 1`;
- choose the outgoing face flux so the reconstructed profile integrates exactly to the retained layer storage;
- share face pressure and face flux between adjacent layers;
- use the remaining external boundary condition as the outer algebraic closure.

This adds no fitted coefficient and no dynamic state, and it naturally permits transient unequal top and bottom layer fluxes.

However, uniform storage tendency is still a **scientific closure assumption**. Existing authority does not prove it is uniquely correct, and C5R/C5T response may not be used post hoc to select it.
