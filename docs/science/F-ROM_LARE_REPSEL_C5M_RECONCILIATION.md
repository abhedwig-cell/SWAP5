# F-ROM-LARE C5M representation reconciliation

C5M returns from the C5B-C5L Reference audit to the central Layer-ROM question. It generates no new hydrological response.

The main conclusion is that current evidence does **not** support a universal minimum number of layers. Comparator-relative minimum dimension changes with material, lower-boundary semantics, prediction horizon, hydrological purpose and comparator strength.

A stronger conclusion does survive those changes: vertical placement matters. Lower-zone-focused R4/R8 representations outperform matched uniform U4/U8 controls in the B14 fixed, B01 dynamic and B14 dynamic evidence. State count and state placement must therefore remain separate design dimensions.

Purpose dependence is also reproducible. In blind B01 fixed-water-table evidence, groundwater-response fidelity can be achieved with fewer states than mapped profile fidelity. The B14 fixed transfer shows the same pattern. Horizon matters independently: the short B01 fixed R4 groundwater frontier becomes R8 over one day.

C5A remains formally negative under its preregistered R2-relative vector. That decision is unchanged. But it is not portable as an absolute B14 dynamic-head representation result: the sole blocker is cancellation-sensitive, R2 is a weak dynamic comparator, and C5C-C5L later showed that the original 10-cm R16 Reference was strongly spatial-resolution dependent under this workload.

The C5J-C5K boundary studies do not supply a replacement Reference formula. C5L instead shows that the unchanged current Reference recovers strong spatial-refinement progress at R2048. R2048 is still not continuum truth.

The unresolved representation-science question is therefore narrow: on fresh blind B14 dynamic prescribed-head histories, which lower-zone-focused layer representations remain competitive with high-resolution Richards controls when Reference numerical uncertainty is made explicit?

C5N is authorized to answer that question prospectively. It must use fresh histories, separate groundwater and profile views, retain placement controls, report cancellation explicitly, and use high-resolution comparator-relative evidence rather than application thresholds. Application acceptance remains blocked by C4U.
