# Native crop accepted-step proposal and atomic day fallback

Bounded qualification unit, 23 October 2026. Composed baseline canonical
`9d86cdf8f`; exact source/native authority remains the existing saturated-flux
and native project owners until this successor is qualified and admitted.

This extends only the opt-in native simple-crop/ETref application route. It
reuses the existing accepted-step proposal runtime unchanged, including its
exact endpoint, hard mass, full/two-half comparison and solver-limited fallback
rules. Default remains false. No shared runtime, solver, constitutive provider,
retry budget, tolerance, physical law or restart schema changes.

The application may enable this policy only for its nonthermal, nonimplicit
pond, frozen-conductivity, Reference-transport, zero-tracer route. Seasonal bottom forcing remains excluded from this option. Positive
initial solute, pond mass, rain/irrigation/runon/drain/seepage concentrations or
dry deposition reject explicitly. Wider chemistry remains outside this unit.

A pilot shows that retained proposals alone can change the trajectory enough
to reject water on day83 at1x and day7 at4x. These failures are retained as
development evidence, not a qualification PASS. On `JOINT_WATER_REJECTED` only,
the opt-in application may retry the same complete reporting interval once
with retained proposals disabled, from the unchanged committed joint state.
Any chemical/commit rejection propagates. Failure of that ordinary retry also
propagates. The optional flag is restored after the retry; no policy cursor
persists between intervals or in restart. The failed attempt's status and work
counters are emitted before retry, so its work is visible and counted in timings.

Qualification must exercise real proposal-caused water failure and check the
complete joint restart bytes before/after rejection. Ordinary default-OFF
outputs must remain byte-exact against the incumbent. Selected O0/O2 whole
97-day1x/4x runs, repeated O2 timing, exact midpoint restart and supported-route
negative controls establish only this bounded constructed zero-tracer domain.
No broader global-error or regional performance claim follows.

For this unit, hard internal balance gates stay exact and independently
reconstructed daily water error must remain below1e-9mm. Maximum daily runoff
and storage differences against the incumbent must stay below0.01mm; seasonal
runoff difference below0.01mm; total evaporation and transpiration differences
below1e-8mm/day. Individual soil/pond evaporation shifts are measured separately.
These criteria are declared before the production implementation, not inferred
from a successful run. Head differences remain observations rather than a
substitute for water/runoff acceptance. No new1e-6 run is selected.

Affected invariants:2,7,8,13,23,25,26. Application orchestration stays outside
the kernel, failed candidates cannot publish, the existing Reference path stays
available and numerical policy is explicit. Qualification uses verified O0/O2
provider reuse because shared production providers remain byte-identical.
No highest-low-air, RossFast extension or unrelated full F-CI is selected.
