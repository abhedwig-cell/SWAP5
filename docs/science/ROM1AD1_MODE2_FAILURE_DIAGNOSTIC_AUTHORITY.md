# ROM-1A-D1 strict mode-2 failure diagnostic authority

The first preregistered ROM-1A library run reached D01 step 20 and then failed before
committing step 21. D01 uses the original strict prescribed-flux mode-2 Reference
sample, so the ROM-0R-R3D4 prescribed-head fallback authority does not apply.

ROM-1A-D1 is diagnostic only.

It rebuilds the exact D01 accepted predecessor through the F-KT
sample/candidate/commit path, computes the already established PUB-P2E21 prospective
representation bound from that accepted pre-solve state, executes the unchanged
strict step 21, and classifies the failed Reference workspace using the PUB-P2E11D
criterion split.

The representation bound is not applied as a solver tolerance in D1. An observed
residual is not an input to the bound formula.

A positive total-only/within-bound classification may justify a separately
preregistered fixed-flux research Reference-policy qualification. It does not
silently reopen or alter the original ROM-1A run.
