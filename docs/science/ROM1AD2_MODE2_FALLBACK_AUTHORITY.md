# ROM-1A-D2 mode-2 strict-first fallback authority

ROM-1A-D1 classified the first D01 library failure as a total-column-only retry. No
local compartment-balance or pressure-head convergence criterion failed, and the
integrated residual was only 13.2% of the independently established prospective
representation bound.

D2 therefore tests a fixed-flux sibling of the already qualified ROM-0R-R3D4
strict-first pattern.

The original mode-2 Reference sample is always attempted first. A successful original
attempt is committed unchanged and no fallback is allowed. A fallback can occur only
after the failed attempt is proven non-mutating, a direct same-state diagnostic
classifies the retry as total-only, and the integrated residual lies inside the
representation bound that was computed from the accepted state before the failed
solver call.

Only the total-column convergence criterion may change on the one same-interval
reattempt. Local balance, head convergence, Newton/backtracking limits, forcing, dt
and the independent transaction mass gate remain frozen.

Qualification uses the two discovery-direction primitives TOP_PLUS and TOP_MINUS for
64 steps each. Held-out histories and B14 remain unopened. A pass qualifies a research
Reference policy for subsequent ROM-1A generation; it does not modify production
Reference semantics.
