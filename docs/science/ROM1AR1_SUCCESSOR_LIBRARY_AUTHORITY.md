# ROM-1A-R1 successor library authority

The first ROM-1A execution stopped at D01 step 21 before a parent result existed.
ROM-1A-D1 classified that failure as a total-column-only Reference retry inside the
pre-existing prospective representation bound. ROM-1A-D2 then independently
qualified the strict-first fixed-flux mode-2 sibling policy on two complete 64-step
directions.

R1 therefore repeats the **unchanged** ROM-1A library design. No history, split,
forcing amplitude, timestep, probe definition or output changes.

Reference authority is now mode-specific:

- mode 2: ROM-1A-D2;
- mode 5: ROM-0R-R3D4.

Both use the same strict-first principle. The original 1e-12 cm/day total-balance
criterion is always attempted first. Fallback is forbidden after an original success.
A failed original attempt must leave committed authority unchanged, must classify as
RETRY_TOTAL_ONLY, and its integrated residual must lie within the prospective bound
computed from the accepted state before the failed solve. Only then may the same
interval be reattempted on a fresh backend with the representation-derived total
criterion. All other solver controls and the independent transaction mass gate remain
frozen.

R1 still generates B01 only. Held-out histories are generated as evaluation data but
may not influence later coordinate enrichment. B14 remains sealed for the declared
material-transfer gate.
