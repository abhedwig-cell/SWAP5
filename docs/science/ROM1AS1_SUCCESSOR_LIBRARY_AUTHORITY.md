# ROM-1A-S1 successor library authority

The first ROM-1A library run remains a valid failed experiment under the original
strict mode-2 Reference control. It is not reclassified.

ROM-1A-D1 identified the D01 failure as total-balance-only and inside the independent
representation bound. ROM-1A-D2 then qualified a strict-first fail-closed fixed-flux
mode-2 fallback on the untouched TOP_PLUS and TOP_MINUS discovery primitives.

S1 changes only the research numerical Reference authority. The original ROM-1A
history alphabet, sequence order, amplitudes, data split, output schema and future
probe design are frozen unchanged.

For mode 2, D2 governs. Every interval first executes the original strict sample.
Fallback is possible only after an immutable failure is independently proven
RETRY_TOTAL_ONLY and inside the pre-solve representation bound.

For pure prescribed-head rise/fall symbols, the existing R3D4 strict-first authority
governs. Combined prescribed-head/top-flux held-out symbols do not inherit D4 fallback
authority. They must succeed strictly or S1 fails.

S1 is the first run allowed to retain the full 768-state library under the combined
qualified research Reference authorities. B14 remains unopened. No reduced coordinate
or closure model may be selected in S1.
