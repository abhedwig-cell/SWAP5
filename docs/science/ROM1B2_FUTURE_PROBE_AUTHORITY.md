# ROM-1B2 frozen-pair future-probe authority

ROM-1B2 is the first predictive-state ambiguity experiment. It does not fit a ROM.

B1 already fixed the collision pairs without seeing any future-probe outcome. B2 must use those exact pair manifests. Each start state is reconstructed from its B01 discovery history and accepted step under the frozen ROM-1A-R2 research Reference policy, then rebased into a fresh committed lineage at probe time zero. No solver scratch is transferred.

The probe set and horizons were frozen in the original ROM-1A preregistration: HOLD, TOP_PLUS, BOTTOM_HEAD_RISE and BOTTOM_HEAD_FALL at 4, 16 and 64 observation steps.

The formal predictive quantity is a **response difference**, not a raw endpoint difference:

`abs[(Y_a(t)-Y_a(0)) - (Y_b(t)-Y_b(0))]`.

This removes the small initial coordinate mismatch that B1 already allowed inside the independently measured theta collision floor and asks whether hidden full-state differences cause different future evolution.

B2 makes formal ambiguity claims only for storage outputs with nontrivial pre-existing B01 numerical Reference scales. For each output the single-trajectory scale is the maximum value already measured before B2 across ROM-0T1Q1 and ROM-0V1. The pairwise separation scale is twice that value, conservatively allowing one Reference-scale contribution from each future trajectory.

Frozen pairwise scales:

- total storage: 7.105427357601002e-14 cm;
- 0-40 cm storage: 7.496585937261102e-4 cm;
- 40-160 cm storage: 7.496585937047939e-4 cm.

A coordinate is discovery-ambiguous if any frozen pair, probe or horizon exceeds any one of those three scales.

Top exchange, bottom exchange and terminal bottom flux are still reported, but they are diagnostic-only here. The existing fixed-flux ROM-0 floor is not an informative state-dependent prescribed-head exchange floor, so B2 may reject a coordinate on storage ambiguity but may not declare complete predictive sufficiency from exchange behavior.

Held-out histories/probes and B14 remain sealed. If the whole Z1/Z2/Z4/Z8 hierarchy is discovery-ambiguous, any enrichment must be proposed from discovery evidence and frozen before held-out evaluation.
