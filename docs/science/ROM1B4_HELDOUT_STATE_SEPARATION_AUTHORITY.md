# ROM-1B4 held-out state-separation authority

Z8+G8 was selected using D01-D08 only. B4 is evaluation, not design.

The complete frozen B01 R2 library is regenerated under the already qualified
strict-first research Reference policy. Pair testing includes every cross-history pair
for which at least one state comes from H01-H04. Discovery-discovery pairs are not
re-used as new evidence because they already selected the candidate.

The same cellwise theta floor and the same induced norm are used. For the seven
unresolved 20-cm bands the candidate norm uses the pair-mean difference. In the
140-160 cm band G8 is present, so that band's induced norm is the exact maximum of the
two cellwise theta differences.

Any held-out-inclusive hidden-state collision rejects the candidate. H01-H04 may not
be used to choose another G component, change the floor, or alter the coordinate.

B4 does not execute future probes. If a collision exists, its pair can only be probed
after a separate preregistration. If no collision exists, the within-material
state-separation gate closes and the next declared challenge is B14 material transfer.
