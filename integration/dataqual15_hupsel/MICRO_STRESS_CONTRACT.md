# Original microscopic stress attribution

The existing de Willigen microscopic root uptake law already accepts the original SWO2ECT1 LRV reduction and SWO2ECT2 KROOT reduction. This successor leaves that law unchanged and adds the missing no-frost RootExtraction_MICRO stress attribution in the same process module.

The original p_func allocates the total accepted uptake deficit using root-length-density times cell thickness, weighted by oxygen and salinity losses. With original Hupsel SWMXDROUGHT0, any active oxygen/salinity reduction receives the full deficit and the drought extension factor is one. With no other stress, the deficit is drought. This is the original diagnostic and root-extension policy, even though another stressor may also have changed the microscopic hydraulic solution. SWMXDROUGHT1 additionally consumes the independently solved optimal-root uptake. A negative remaining deficit is rejected, not clamped into a negative oxygen loss. The helper introduces no water sink and changes no mass ledger or state owner.

The source skips root extraction for PTRA below1e-10 before assigning saved ALPDRYNODRTZ (rootextraction275), while integral.f90296 continues to accumulate that saved value. The helper therefore accepts optional previous_drought_factor, requiring zero actual uptake and retaining this exact preceding physical observation on zero-demand steps. The caller owns its cloned, rolled-back and persisted continuation; the helper owns no state. An unsupplied preceding observation explicitly initializes to zero, corresponding to the donor static-storage starting value; it must not replace a positive-demand history. Otherwise the factor is exactly1-drought_loss/PTRA.

Verification uses the existing compiled micro source oracle, extended by literal extraction of the pinned original p_func and RootExtraction_MICRO attribution statements. It retains the existing de Willigen cases, adds original Hupsel potato scalar parameters on that incumbent oracle profile, and compares the no-frost partition, zero demand and invalid optimal-root receipt. The profile remains the existing two-node component oracle; this is not original Hupsel project execution or additional migrated days.
