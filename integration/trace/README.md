## Non-negotiable prospective rule

A case is confirmatory prospective evidence only when its substantive scientific discrepancy and disposition were not known before its first TRACE candidate registration. Previously known SWAP/SWAP5 findings are historical/pilot material even if repair or admission happens after this protocol freeze.

Operational sequence:

`REGISTER -> FREEZE -> ELIGIBILITY -> BASELINE REGRESSION REPLAY -> INDEPENDENT EVIDENCE -> CLASSIFY -> ADJUDICATE -> REPAIR/PRESERVE -> QUALIFY -> CLOSE`

Files in this directory define the study protocol, denominator, candidate and exclusion registries, coding scheme, replay method and independent-rater procedure.
