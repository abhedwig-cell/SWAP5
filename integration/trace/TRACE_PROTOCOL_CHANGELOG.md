# TRACE protocol changelog

## v0.2 - 2026-09-19

Historical/pilot calibration performed before any prospective candidate was registered.

Changes:
- add `NUMERICAL` as a scientific-consequence dimension;
- add `MODEL_EVOLUTION_REQUIRED` as a resolution disposition;
- record three known SWAP and three known ANIMO cases as a strictly historical pilot corpus;
- preserve all v0.1 research questions, hypotheses, eligibility rules, knowledge boundary, denominator, regression counterfactual and kill criteria.

Reason: the historical cases distinguish numerical consistency defects from physical/structural change, and local implementation repair from cases where a defensible solution requires additional scientific state or process representation.

No prospective candidate existed when this amendment was made.

## v0.1 - 2026-09-19

Initial protocol freeze on dedicated research branch.

Changes established:
- prospective knowledge boundary;
- historical/pilot separation;
- discrepancy episode as primary unit;
- reconciled scientific element as denominator;
- preregistered representation-relation classes;
- open mechanism coding;
- pre-resolution evidence freeze;
- case-level regression counterfactual;
- independent coding requirement;
- duration/exposure stop rule;
- explicit kill criteria.

No prospective cases have been pre-populated in the candidate register.
