# TRACE independent-rater guide v0.1

Independent coding is performed before consensus.

For the assigned case, the second rater receives the frozen evidence bundle and current codebook but not the primary rater's final codes where practical.

Independently assign:

1. inclusion/exclusion;
2. structural relation class(es);
3. literal discrepancy mechanism description;
4. mechanism code if an existing code clearly applies;
5. potential scientific consequence;
6. demonstrated scientific consequence;
7. regression-counterfactual interpretation;
8. final disposition, if evidence is sufficient;
9. confidence and unresolved ambiguity.

At least 30% of confirmed prospective cases must be independently rated. The subset must include both models and several mechanism classes.

Freeze both ratings before reconciliation. Report raw agreement. Use Krippendorff's alpha for suitable nominal fields when the dataset permits it. Retain disagreement patterns as data rather than deleting them after consensus.

When the disagreement concerns scientific authority rather than coding terminology, obtain domain review where feasible and document why one authority was accepted, rejected or left unresolved.
