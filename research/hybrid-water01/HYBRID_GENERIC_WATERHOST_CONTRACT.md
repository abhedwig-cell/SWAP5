# Explicit project state for the hybrid waterhost

Proposed implementation successor to PR1620/1624, base canonical01a9d29c3.
The existing original Andelst macro/Cauchy route remains the admitted reference
for this host. The independent native Grassgrowth thermal route is unchanged.

The host must own project identity, original calendar origin, node count and
the existing project water acceptance budget explicitly. Pressure is an owned
allocatable component of each cloned transaction state; different grids must
not share storage. Committed clocks remain owned by the existing kernel.
The legacy Andelst wire protocol and112-node/35795/1e-6 defaults remain supported.
The explicit project protocol carries each column's nodes and epoch before
its initial physical receipt. Unknown model/framing/grid/clock refuses before
acceptance; the caller cannot enlarge a registered water budget.

Original Grassgrowth is113-node, nonmacro, no snow and prescribed groundwater.
It is a separate explicit water-only prototype with1e-10cm daily budget.
Do not execute the Andelst macro/Cauchy retry receipt for that configuration.
Absent macro stocks are zero physical contributions, not allocated legacy macro
arrays. Preserve original physics and original inputs. The donor computes crop,
atmospheric forcing and heat as before; this does not qualify its thermal
trajectory under the native1e-5C temporal budget or replace that admitted route.

The existing schema3 durable publication remains kernel-acceptance gated.
Its exact source/project/input binding must distinguish the new project.
Nonmacro auxiliary restart must explicitly identify its mode, grid and clock;
restore required old timestep and canopy state without touching macro arrays.
The original macro payload and corrective route remain unchanged for Andelst.
The native restart must preserve original crop, forcing, temperature and water
state; own fresh-process equality is mandatory before a broader scope claim.

Acceptance is the bounded original four-day prototype, own2-to4 continuation,
distinct-instance/refusal controls, coldO0/O2 variable-grid real kernel contracts
and Andelst preservation. A successful initial segment is not a full original
project or scientific qualification. No full trajectory is selected. Persist
failed contracts and use the existing two-repair stop rule.
