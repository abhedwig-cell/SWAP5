# Qualification boundary

F-TB13 qualifies only durable preservation of the recovered analytical/reference definitions and their expected result identities, plus the recorded fresh B1.11 replay evidence.

It does not qualify the recovered framework executable as canonical B0, the historical steady-state-solute table as a hard release oracle, Basha (1999), the complete historical verification framework, or SWAP5 production-solver equivalence.

Any future executable use of the preserved benchmark definitions against a changed reference or SWAP5 production implementation requires a separately identified current-source qualification step.
